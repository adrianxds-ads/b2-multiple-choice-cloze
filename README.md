# B2 Multiple-Choice Cloze

PWA de entrenamiento para Cambridge B2 First · Reading and Use of English · Part 1.

- Banco cerrado de 120 preguntas originales.
- 15 preguntas por sesión.
- 20 segundos por pregunta.
- Cuatro opciones barajadas en cada aparición.
- Estadísticas persistentes y revisión final de errores.
- Diseño heredado de Adaptive English / Adaptive Phrasal Verbs.
